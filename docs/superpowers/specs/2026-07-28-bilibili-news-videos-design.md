# B站新闻视频推送设计

## 目标

日报新增央视频、央视新闻、1818黄金眼和一觉醒来发生啥发布的新闻视频；每个账号每日最多两条，只推送北京时间当天或前一天发布且从未发送过的视频。

## 数据与筛选

使用 `bilibili-api-python` 查询固定 UID 的投稿视频。以 BV 号作为唯一键，发布时间须落在“昨天 00:00 至当前运行时刻”之间。账号单次查询失败只记录日志，不影响日报其他部分。

## 去重

`data/sent_bilibili_videos.json` 记录 `bvid` 与发送日期。每次成功选中视频后更新台账，保留 90 天。GitHub Actions 在日报成功后提交该文件；本地 NAS 运行使用同一文件。

## 输出

网页在热搜前增加“B站新闻视频”区块；企业微信新增一条 Markdown 消息，显示 UP 主、标题、发布时间与视频链接。

## 运行约束

默认无 Cookie 调用；可选环境变量 `BILIBILI_SESSDATA` 用于遇到风控时增强稳定性。公开视频获取失败时安全跳过，不编造视频信息。
