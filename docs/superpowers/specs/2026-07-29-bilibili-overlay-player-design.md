# B站视频放大播放设计

## 目标

在每日新闻网页中，为每条 B 站视频提供“放大播放”按钮。点击后使用网页内的全屏遮罩显示播放器，不依赖微信或企业微信内置浏览器的原生 iframe 全屏能力。

## 交互与实现

- 每个视频卡片继续展示 16:9 的内嵌播放器。
- 新增“放大播放”按钮，按钮保存该视频的官方播放器 URL 和标题。
- 页面只创建一个全屏遮罩；点击任一按钮时，遮罩显示对应视频的 iframe。
- 遮罩提供“关闭”按钮；点击遮罩空白区域或按 Escape 也会关闭。
- 遮罩显示时锁定页面滚动；关闭后恢复滚动，并清空 iframe 地址以停止后台播放。

## 兼容与边界

- iframe 使用 B站官方播放器 URL，并补齐 `allowfullscreen="true"`、`webkitallowfullscreen`、`mozallowfullscreen`、`scrolling="no"` 和 `frameborder="0"`。
- 不下载、缓存、转码或代理任何视频。
- 原“打开 B站原页面”链接继续保留。
- 若浏览器禁用 JavaScript，仍可使用卡片内播放器与原页面链接。

## 验证

- HTML 单元测试确认有放大按钮、遮罩、关闭按钮和播放器 URL。
- 测试确认 iframe 含官方推荐的全屏相关属性。
- 完整 pytest 套件必须通过。
