# B站嵌入式播放器设计

## 目标

让日报网页内的 B 站新闻视频可以直接播放、暂停和拖动进度条，避免跳转到移动端普通详情页后出现下载 App 引导。

## 方案

每条 `BilibiliVideo` 保留原始详情页 URL，并新增一个由 BV 号生成的官方嵌入式播放器 URL：

`https://player.bilibili.com/player.html?bvid=<BV号>&page=1&high_quality=1&danmaku=0`

网页版在每条视频下放入响应式 `iframe`，播放器按 16:9 显示并允许全屏。企业微信消息的“观看视频”链接改为播放器 URL；网页保留“打开 B站原页面”作为兼容性备用入口。

## 边界与失败处理

- 不下载、不缓存、不转码视频；静态站点容量不受视频体积影响。
- 不改变 B 站视频的抓取、筛选、去重和发送历史。
- 播放器被 B 站网络策略拦截时，读者仍可使用原页面链接观看。
- 所有 URL 从 BV 号生成，不接受外部输入拼接为 HTML。

## 验证

- 单元测试确认播放器 URL 使用正确 BV 号和参数。
- HTML 测试确认存在 iframe、备用原页面链接和 `allowfullscreen`。
- 企业微信消息测试确认“观看视频”使用播放器 URL。
- 完整测试套件必须通过。
